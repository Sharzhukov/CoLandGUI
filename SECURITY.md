# Security Policy 🔒

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.0.x   | ✅ Fully supported |
| < 1.0   | ❌ Not supported   |

## Reporting a Vulnerability

If you discover a security vulnerability, **please do NOT open a public issue**.

Instead, contact the project maintainer directly:

- GitHub: [@Sharzhukov](https://github.com/Sharzhukov)
- Email: i@sharzhukov.ru

Please include:
- A clear description of the vulnerability
- Steps to reproduce it
- The version of CoLand affected
- Any potential fixes (if known)

## Response Time

We will acknowledge your report within **48 hours** and provide a timeline for a fix.

## Disclosure Policy

- Once the vulnerability is fixed, we will release a patch.
- We will credit the reporter (if you wish) in the release notes.

## Security Best Practices

- Always use the latest stable version.
- Keep your dependencies up to date (see NOTICE for details).
- Do not share master keys or passwords in code or commits.

## Contact

For security-related questions:
- GitHub: [@Sharzhukov](https://github.com/Sharzhukov)
- Email: i@sharzhukov.ru
