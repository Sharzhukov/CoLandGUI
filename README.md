# 🏛️ ColoLand

**ColoLand** — это пошаговый симулятор выживания колонии на C++ с элементами стратегии и RPG.  
Игрок управляет группой поселенцев, их здоровьем, настроением, браками и ресурсами.

---

## 🎮 Особенности

- 🧑‍🌾 **5 профессий:** Farmer, Builder, Medic, Scout, Guard
- ❤️ **Динамика состояния:** здоровье, голод, настроение
- 💍 **Социальные связи:** свадьбы и отношения
- 📅 **Пошаговая симуляция:** каждый день меняет состояние колонии
- 💾 **Сохранение и загрузка:** состояние сохраняется в файл
- 🖥️ **Цветной интерфейс:** подсветка статусов в консоли

---

## 🛠️ Стек технологий

- **Язык:** C++17
- **Библиотеки:** STL (vector, string, algorithm, fstream)
- **Сборка:** CMake (Windows, macOS, Linux)
- **Среда:** Xcode / VS Code / Qt Creator

---

## 🚀 Сборка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/ColoLand.git
cd ColoLand

# Собрать через CMake
mkdir build && cd build
cmake ..
make

# Запустить
./ColoLand
