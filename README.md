# 🏛️ CoLand — Colony Survival Simulator

**CoLand** — это пошаговый симулятор выживания колонии на C++ с элементами стратегии и RPG.  
Игрок управляет группой поселенцев, их здоровьем, настроением, браками и ресурсами.

Проект написан на **C++17** с использованием **STL** и собран с помощью **CMake**.  
Поддерживает **консольный (TUI)** и **графический (GUI)** интерфейсы.

---

## 🎮 Особенности

- 🧑‍🌾 **5 профессий:** Farmer, Builder, Medic, Scout, Guard
- ❤️ **Динамика состояния:** здоровье, голод, настроение
- 💍 **Социальные связи:** свадьбы и отношения
- 📅 **Пошаговая симуляция:** каждый день меняет состояние колонии
- 💾 **Сохранение и загрузка** (в разработке)
- 🖥️ **Цветной консольный интерфейс** и **графический интерфейс (GUI)**

## 🚀 Сборка и запуск

### Требования

- **CMake** 3.15+
- **Компилятор C++17** (Clang, GCC, MSVC)
- **Git** (для клонирования)

### Сборка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/sharzhukov/CoLand.git
cd CoLand

# 2. Создать папку для сборки
mkdir build && cd build

# 3. Сгенерировать Makefile
cmake ..

# 4. Собрать проект
make

# 5. Запустить (TUI)
./CoLand
```

### Сборка (GUI)

```bash
# 1. Включить GUI в CMake
cmake .. -DENABLE_GUI=ON

# 2. Собрать
make

# 3. Запустить (GUI)
./CoLandGUI
```

### Сборка для разных систем

```bash
# Debug (с отладочной информацией)
cmake .. -DCMAKE_BUILD_TYPE=Debug

# Release (оптимизированный)
cmake .. -DCMAKE_BUILD_TYPE=Release

# Xcode (macOS)
cmake -G Xcode ..

# Visual Studio (Windows)
cmake -G "Visual Studio 17 2022" ..
```
